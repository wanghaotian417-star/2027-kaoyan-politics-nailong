# 2027 考研政治一页纸 · 奶娃养成版

一份可以直接下载、离线打开的考研政治学习网页。它把《27 考研澄潇宇政治一页纸》整理为 100 个可检索的知识点，并加入标注、抽背、复习记录，以及会随学习行为互动的奶娃伙伴。原页面署名“公众号：风中羽小易，免费制作分享”；本仓库保留该署名并分享奶娃养成版，不售卖资料，也不代表任何角色或资料的官方发布方。

## 下载与使用

1. 在本仓库下载 [`downloads/奶娃养成版-离线HTML.zip`](downloads/奶娃养成版-离线HTML.zip)，解压后双击 `index.html`。
2. 也可以直接下载仓库根目录的 [`index.html`](index.html)。它是完整网页，不需要安装软件、启动服务或连接网络。
3. 学习记录只保存在你当前浏览器的本地存储中。换设备或清理浏览器前，请在页面右上角“备份”中导出进度；发送 HTML 文件本身不会附带个人学习记录。

> 手机浏览器对本地 `file://` 文件的支持不同。若双击无法正常打开，可以换用支持本地 HTML 的浏览器，或使用[在线预览](https://nailong-politics-study-2027-1105.wanghaotian417.chatgpt.site)。在线预览在中国大陆各地区的连通性尚未逐一验证。

## 能做什么

- 阅读、搜索和定位 100 个知识点；在马原、史纲等学科之间切换。
- 选中文字高亮、遮挡、写笔记；支持框选遮挡、逐条揭晓、撤销与回收站。
- 随机自测、卡片抽背、知识图谱定位，以及按知识点记录掌握状态和复习遍数。
- 导出、导入进度备份；切换明暗主题。
- 点击、拖动奶娃伙伴，查看等级、心情、徽章与连续学习天数。伙伴会随阅读、自测、掌握等操作切换状态。
- 25/5 或 50/10 专注模式：专注正向计时，每满 1 分钟获得 1 XP；达到目标后进入休息。每日经验总上限为 100 XP，计时与养成记录可在刷新后恢复。
